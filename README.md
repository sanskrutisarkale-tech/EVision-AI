# 🚗 EVision-AI

### AI-Powered EV Fleet Optimization Agent

EVision-AI is an AI-powered agent designed to optimize Electric Vehicle (EV) fleet charging decisions based on electricity prices, vehicle availability, and charging requirements.

## 🎯 Problem Statement

EV fleet operators need to decide when and which vehicles should be charged. Charging at the wrong time can increase electricity costs and reduce fleet efficiency.

## 💡 Our Solution

EVision-AI analyzes the available information and helps select an efficient charging plan. It provides:

- ⚡ Electricity price information
- 🚗 EV fleet information
- 🤖 Agent activity
- 📊 Charging plan
- 💡 Explanation of the decision
